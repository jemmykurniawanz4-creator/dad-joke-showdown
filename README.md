An entry for the [make.fun](https://make.fun) bounty
["Dad Joke Showdown"](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5).

The entry is one dad joke, a double pun delivered deadpan the way a dad
would tell it across the dinner table: the calendar's days are numbered, so
it should just take it one day at a time.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the joke to
`/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that
environment variable is set. Two runs write identical bytes.
